# 60-second real-app demo

Record the app window only, without terminal credentials or account menus. Use the Last Light example as a reliable fallback, and label it “previously generated example” if you load it rather than generate it live.

| Time | Screen action | Narration |
| --- | --- | --- |
| 0–8s | Empty studio; type a short lighthouse rescue game prompt. | “Board Studio turns a board-game idea into something you can edit and put on a real table.” |
| 8–18s | Show the actual generated proposal. Cut waiting time with an on-screen “generation time shortened” label if necessary. | “Astra works through the mechanics and generates the board, pieces, cards and rules as one editable document.” |
| 18–29s | Apply the proposal. Orbit the scene and select a lighthouse. | “These are editable 3D parts, not a flat image. I can change a component directly or ask for a focused revision.” |
| 29–40s | Show an actual AI revision or its validated proposal. | “The assistant receives the current game, selection and optional viewport. Changes are previewed before I keep them.” |
| 40–50s | Switch to Play; move a pawn or draw a card. | “The free tabletop lets me try the components. The rules are manual, so I can discover what needs another playtest.” |
| 50–60s | Switch to Print; show board, tokens, cards and rules. | “Then I print a kit and test it with people. One workspace takes the idea from conversation to a physical prototype.” |

If the actual recording does not demonstrate an AI revision, replace the 29–40s sentence with “I can inspect every part and undo edits without losing the generated game.” Do not imply unrecorded behavior occurred.

## Recording and submission
1. Run the local app and prepare the real generation before recording.
2. Use QuickTime, Loom, or Cap to record approximately one minute with narration.
3. Upload the recording to a publicly accessible link (unlisted YouTube or public Loom/Drive are options listed by the event).
4. Open that link while signed out and check playback.
5. Add the video URL and public repo URL to the submission form.

## Three-minute finalist demo
- 0:00–0:30: State the idea and show conversation.
- 0:30–1:20: Generate/apply a game; inspect geometry and rules.
- 1:20–2:00: Request a focused change and apply/undo it.
- 2:00–2:30: Try tabletop movement and cards.
- 2:30–3:00: Print kit, explain the structured document and validation.
